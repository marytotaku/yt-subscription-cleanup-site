Privacy Policy

yt-subscription-cleanup · Last updated: 2026-11-11

Who uses this app

yt-subscription-cleanup is a personal tool. Its only user is its owner, who signs in with their own Google account. It is not offered to anyone else.

Data accessed

With the owner's consent (scope youtube.force-ssl), the app reads the owner's YouTube subscriptions and channel information, and removes subscriptions only when the owner confirms each one.

Where data is kept

  • All data stays on the owner's own computer. The OAuth token is stored locally with owner-only file permissions.
  • No data is sold, shared, or sent to any server operated by the developer. There is no such server.
  • No advertising, analytics, or tracking.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local data folder removes everything the app stored.

プライバシーポリシー（日本語）

本アプリは所有者本人だけが使う個人用ツールです。所有者の同意のもとで YouTube の購読情報を読み取り、 所有者が確認したチャンネルだけ購読を解除します。データはすべて所有者のコンピューター内に保存され、 第三者への提供や外部サーバーへの送信は行いません。アクセス権は Google アカウントの設定からいつでも取り消せます。
